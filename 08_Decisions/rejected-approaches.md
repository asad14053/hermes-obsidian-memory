# Rejected / Deprioritized Approaches

- Do not use one expensive model for every agent step.
- Do not load the whole long-term memory archive into every prompt.
- Do not assume free endpoints are private.
- Do not expose Hermes directly on random public port once Traefik works.
- Do not install Caddy/Nginx when Traefik already handles TLS.
- Do not equate Visium spots with Xenium cells.
- Do not assume donor match = same section.
- Do not store raw conversation transcripts as default active memory.
- Do not make TTS mandatory.
