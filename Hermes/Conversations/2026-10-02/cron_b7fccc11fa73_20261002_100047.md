# arXiv Research

Search and retrieve academic papers from arXiv via their free REST API. No API key, no dependencies — just curl.

## Quick Reference

| Action | Command |
|--------|---------|
| Search papers | `curl "https://export.arxiv.org/api/query?search_query=all:QUERY&max_results=5"` |
| Get specific paper | `curl "https://export.arxiv.org/api/query?id_list=2402.03300"` |

## Searching Papers

The API returns Atom XML. Parse with `grep`/`sed` or pipe through `python` for clean output.

### Basic search

```bash
curl -s "https://export.arxiv.org/api/query?search_query=all:GRPO+reinforcement+learning&max_results=5"
```

### Clean output (parse XML to readable format)

```bash
curl -s "https://export.arxiv.org/api/query?search_query=all:GRPO+reinforcement+learning&max_results=5&sortBy=submittedDate&sortOrder=descending" | python -c "
import sys, xml.etree.ElementTree as ET
ns = {'a': 'http://www.w3.org/2005/Atom'}
root = ET.parse(sys.stdin).getroot()
for i, entry in enumerate(root.findall('a:entry', ns)):
    title = entry.find('a:title', ns).text.strip().replace('\n', ' ')
    arxiv_id = entry.find('a:id', ns).text.strip().split('/abs/')[-1]
    published = entry.find('a:published', ns).text[:10]
    authors = ', '.join(a.find('a:name', ns).text for a in entry.findall('a:author', ns))
    summary = entry.find('a:summary', ns).text.strip()[:200]
    cats = ', '.join(c.get('term') for c in entry.findall('a:category', ns))
    print(f'{i+1}. [{arxiv_id}] {title}')
    print(f'   Authors: {authors}')
    print(f'   Published: {published} | Categories: {cats}')
    print(f'   Abstract: {summary}...')
    print(f'   PDF: https://arxiv.org/pdf/{arxiv_id}')
    print()
"
```

## Search Query Syntax

| Prefix | Searches | Example |
|--------|----------|---------|
| `all:` | All fields | `all:transformer+attention` |
| `ti:` | Title | `ti:large+language+models` |
| `au:` | Author | `au:vaswani` |
| `abs:` | Abstract | `abs:reinforcement+learning` |
| `cat:` | Category | `cat:cs.AI` |
| `co:` | Comment | `co:accepted+NeurIPS` |

### Boolean operators

```
# AND (default when using +)
search_query=all:transformer+attention

# OR
search_query=all:GPT+OR+all:BERT

# AND NOT
search_query=all:language+model+ANDNOT+all:vision

# Exact phrase
search_query=ti:"chain+of+thought"

# Combined
search_query=au:hinton+AND+cat:cs.LG
```

## Semantic Scholar (Citations, Related Papers, Author Profiles)

arXiv doesn't provide citation data or recommendations. Use the **Semantic Scholar API** for that — free, no key needed for basic use (1 req/sec), returns JSON.

### Get paper details + citations

```bash
# By arXiv ID
curl -s "https://api.semanticscholar.org/graph/v1/paper/arXiv:2402.03300?fields=title,authors,citationCount,referenceCount,influentialCitationCount,year,abstract" | python -m json.tool

# By Semantic Scholar paper ID or DOI
curl -s "https://api.semanticscholar.org/graph/v1/paper/DOI:10.1234/example?fields=title,citationCount"
```

### Get citations OF a paper (who cited it)

```bash
curl -s "https://api.semanticscholar.org/graph/v1/paper/arXiv:2402.03300/citations?fields=title,authors,year,citationCount&limit=10" | python -m json.tool
```

### Get references FROM a paper (what it cites)

```bash
curl -s "https://api.semanticscholar.org/graph/v1/paper/arXiv:2402.03300/references?fields=title,authors,year,citationCount&limit=10" | python -m json.tool
```

### Search papers (alternative to arXiv search, returns JSON)

```bash
curl -s "https://api.semanticscholar.org/graph/v1/paper/search?query=GRPO+reinforcement+learning&limit=5&fields=title,authors,year,citationCount,externalIds" | python -m json.tool
```

- **1. READ NOW — The recoverable resolution of cellular perturbation-response prediction**  
  **Citation:** Huang, Wang, Li & Wilson. bioRxiv v1, October 1. [Paper](https://www.biorxiv.org/content/10.64898/2026.09.30.755756v1)  
  **Problem / method:** Can models recover context-specific intervention effects rather than baseline identity and shared responses? The authors separate these components using held-donor tests, independent replicates, State-model audits and target-hidden drug-response prediction.  
  **Key result:** T-cell predictions achieved approximately **0.989 state-expression correlation**, yet donor-specific response R² was non-positive. With **4,649 of 4,650** drug–context entries observed, context-specific recovery remained **0.1107**—a replicate-based statistic, not ordinary R².  
  **What’s new / AIVC relevance:** “Context geometry compression” exposes the gap between recognizing a context and predicting its response rules. This directly challenges your spatial/context-conditioned simulator premise.  
  **Weakness:** These results do not establish a universal predictability limit; conclusions depend on datasets, available inputs and tested estimators.  
  **Research idea:** Test whether neighborhood information improves **replicate-calibrated, donor-specific response residuals**, with both gene-level and prespecified pathway endpoints.

- **2. READ NOW — Deep learning perturbation models can outperform baselines on calibrated metrics**  
  **Citation:** Miller et al. *Nature Biotechnology*, October 1. [Paper](https://www.nature.com/articles/s41587-026-03307-w)  
  **Problem / method:** Are weak benchmark scores caused by weak models or insensitive metrics? Introduces an interpolated-duplicate positive control and a “dynamic range fraction” calibration framework across **14 datasets and 18 metrics**.  
  **Key result:** Weighted and rank-based metrics reveal perturbation-specific signal that conventional metrics can obscure. PRESAGE exceeded the additive baseline on **15 of 18 metrics in Wessels23**—not universally across datasets.  
  **What’s new / AIVC relevance:** Benchmarks themselves must demonstrate sensitivity before supporting architectural conclusions. This refines—not removes—your requirement to beat simple baselines.  
  **Weakness:** The positive control requires measured perturbation outcomes; it is a diagnostic, not a deployable unseen-target predictor. Metric and DEG-weighting choices influence rankings.  
  **Research idea:** Preregister a graph-versus-transformer benchmark with replicate controls, mean/linear/additive baselines, weighted error, retrieval and context-residual metrics.

- **3. READ NOW — When Do Biological Reasoning Models Use Their Biological Inputs?**  
  **Citation:** Fang, Thoduguli, Fesser, Zhang, Kakade & Zitnik. arXiv:2610.00898v1, October 1. [Paper](https://arxiv.org/abs/2610.00898v1)  
  **Problem / method:** Does strong performance mean a model uses its biological representations? Audits six systems through input perturbations, conflicting text/representation pairs, linear probes and reasoning traces.  
  **Key result:** BioReason and BioReason-Pro followed conflicting text in **97.9% and 99.7%** of cases, despite informative biological embeddings. Other systems, including CellWhisperer, benefited from biological inputs.  
  **What’s new / AIVC relevance:** Separates information **encoded** from information **used**. Your graph or spatial encoder could be present but functionally ignored.  
  **Weakness:** Primarily an audit of LLM-linked reasoning systems; findings cannot automatically generalize to perturbation simulators. Shuffled inputs can also be out of distribution.  
  **Research idea:** Compare matched, missing and within-cell-type-permuted neighborhood inputs, plus degree-preserving graph rewiring. Require incremental predictive value, not attention visualizations alone.
