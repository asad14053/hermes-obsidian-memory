# Hermes Memory

Obsidian is the active external memory provider; canonical vault: /opt/data/obsidian-vault; plugin: /opt/data/plugins/obsidian. The prior /opt/data/Obsidian Vault directory is a temporary migration source/backup and should not be treated as canonical.
§
Bangladesh Ministry Monitor cron jobs use the canonical Obsidian vault `/opt/data/obsidian-vault` and current project folder `/opt/data/obsidian-vault/Bangladesh_Monitor` (underscore). References to `/opt/data/Obsidian Vault`, `Bangladesh-Monitor`, or another vault should be corrected unless the user explicitly migrates the project.
