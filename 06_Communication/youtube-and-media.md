# YouTube and Media

## Use cases
- tutorial research
- political/legal/social research
- source validation
- news/event memory
- script generation
- photo-card/reel production

## Agent rules
- Prefer legitimate/reliable sources.
- Preserve references.
- Separate hook, research context, validation/source evidence.
- Never let a generation model invent sources.
- Reuse research memory across multiple content pieces.

## Production
- Reel Factory/OpenClaw target high-volume automation.
- Local/free models preferred.
- FFmpeg/NVENC used for rendering.
