# Reel Factory — Overview

## Objective

Build a local-first automated reel/photo-card factory on Windows using local/open models, stock or validated images, text overlays, optional voice/music, and FFmpeg.

## Scale targets

- prototype ~10/day,
- then ~100/day,
- long-term experiments up to ~1000/day.

## Design principles

- avoid paid APIs,
- LM Studio/local LLMs,
- FFmpeg + NVENC,
- optional/reversible TTS,
- reusable scripts/assets,
- agent automation only where it adds value.

## Languages

- Bangla and English.
- Bangla should be fluent and natural.
