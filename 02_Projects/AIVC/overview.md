# AIVC — Overview

AIVC = AI Virtual Cell.

## Working concept

Predictive cellular simulator integrating:
- gene expression,
- epigenetic state,
- protein interactions,
- spatial context,
- disease state,
- perturbations.

## Current phase

Learning/design rather than finalized training.

Main interests:
- GNNs,
- transformers,
- graph/transformer hybrids,
- causal perturbation models,
- graph construction/update,
- unseen-perturbation generalization.
