# AIVC — Overview

AIVC = AI Virtual Cell.

## Working concept

**User-supplied outline received September 23:** [[02_Projects/AIVC/project-outline|Project outline — original PDF and multimodal diagram]]. The core design separates cell identity and local microenvironment into a universal representation (UR), then uses a virtual instrument (VI) to predict cell-type-specific activity under altered environments. The accompanying diagram extends this to multimodal inputs, explicit gene perturbations, hierarchical neighborhood attention, and a conditional VAE. These are proposed designs, not completed results; the PDF and diagram are preserved as distinct specifications.

Earlier broad interests included a predictive cellular simulator integrating:
- gene expression,
- epigenetic state,
- protein interactions,
- spatial context,
- disease state,
- perturbations.

## Current phase

Learning/design rather than finalized training.

Main interests:
- GNNs,
- transformers,
- graph/transformer hybrids,
- causal perturbation models,
- graph construction/update,
- unseen-perturbation generalization.
