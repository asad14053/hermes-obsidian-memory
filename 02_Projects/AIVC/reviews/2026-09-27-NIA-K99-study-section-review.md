# SIGNIFICANCE — 7

### Why should NIA care?

A persuasive application would identify a defined aging- or AD-related environment that changes a consequential cellular response, show that measuring that environment improves prediction beyond cell identity, and validate a biological consequence. The current record does not name the population, exposure, pathology contrast, intervention class, measured response or functional endpoint. An expression reconstruction model with AD listed as a later application is insufficient for this proposed NIA program.

Chronological aging, AD pathology and experimentally induced stress are different variables. A covariate named age is not a demonstrated aging mechanism. An AD exposure model must also state which aspect of human disease it represents and which aspects it cannot reproduce. These are design requirements, not claims that a particular system is already available.

### Does SCZ help?

SCZ/GeneBridge is the genuine technical foundation and can support spatial preprocessing, measured-target evaluation and donor-level inference. It is not AD or perturbation preliminary evidence. Within an NIA application, keep it as bounded methodological preparation or a later transport test. A parallel SCZ disease aim would dilute focus unless the same defined biological mechanism and estimand connect the diseases; that connection is not documented. If the strongest question remains SCZ-specific, retain it rather than relabeling it for NIA.

# INNOVATION — 6

The potentially novel contribution is not another collection of foundation embeddings, attention, spatial pooling and a generative decoder. It is a falsifiable account of **when tissue environment adds transferable response information, when that information fails, and which predicted contrasts survive controlled manipulation**.

The [[02_Projects/AIVC/literature/2026-09-25-literature-radar|September 25 radar]] already identifies overlapping or challenging work: CellAudit for useful input dependence; SpaFactor for lightweight context modeling; DePass for multimodal integration; Hou and colleagues for identification under hidden variables/selection; PRAXIS for evidence-aware execution. These are secondary summaries read from the existing radar, not newly fetched or reproduced papers in this review. No numerical performance claims from those papers are needed to maintain the prior assessment.

Consequences for AIVC:
- Prove that environment contributes useful measured-target information; an executed branch, attention weight or changed output is not sufficient.
- Compare with identity-only and simple pooled-context predictors before claiming the hierarchical model is necessary.
- Do not call integration quality intervention validity.
- Do not infer regulatory mechanism from attention or temporal dynamics from cross-sectional snapshots.
- Treat a simulated contrast as a prediction unless an intervention estimand and identification argument support stronger language.

The novelty burden is unchanged since yesterday. More architectural components without evidence of incremental value make the proposal larger, not necessarily more innovative.

# CENTRAL HYPOTHESIS

## Current state

The supplied outline offers a testable predictive premise: local environment contains activity information beyond identity. It does not establish a frozen NIA-specific hypothesis or a valid test of its stronger intervention interpretation. See [[02_Projects/AIVC/project-outline]] and [[02_Projects/AIVC/current-state]].

## One strong central hypothesis — proposed, not adopted

**In one defined human neural cell population, an AD-associated inflammatory microenvironment modifies the population response to a prespecified perturbation class; baseline neighborhood programs will improve response prediction across held-out donors beyond identity alone, and controlled manipulation of that environment will reproduce the registered response direction and functional consequence.**

Inflammation is a proposed biological focus, not a project finding. Before using this hypothesis, select the population, exposure, intervention, timing, response program and functional assay using actual data/access. Its falsifiers are no reproducible context benefit, comparable benefit under appropriate matched shuffling, failed donor transport, or experimental contradiction of the prespecified response. Predictive success alone does not establish the experimental part.

# SPECIFIC AIMS

### Proposed Aim 1 — Establish the value and limits of AD-relevant spatial context

Choose one eligible system, a frozen measured activity target and explicit deployment-available inputs. Compare identity-only, pooled-context and a modest nonlinear predictor on locked donor splits. Assess matched context replacement, measured-only outcomes, calibration and independently reserved donors/cohort.

**Measurable outputs:** accession/metadata inventory, donor and modality overlap manifest, fold-local processing, held-out predictions, paired donor loss contrasts and context-use controls. Prespecify a biologically meaningful improvement and uncertainty target from actual pilot variability rather than inheriting an arbitrary percentage.

**Fallback:** if complex modeling fails but simple context helps, retain the simple model. If context itself adds no supported information, report that boundary and revise the premise rather than escalating architecture.

### Proposed Aim 2 — Test a limited environment-by-perturbation contrast

In an accessible AD-relevant neural/glial system, manipulate a specified exposure and perturbation with controls, independent biological replication and a functional readout. Choose the contrast from biological rationale and simple-model predictions as well as AIVC so that the experiment does not require Aim 1 to produce a sophisticated winning model.

**Measurable outputs:** protocol, manipulation checks, frozen predictions, expression and functional response estimates, and replication/uncertainty at the correct experimental unit.

**Fallback:** distinguish failed manipulation, insufficient assay precision and falsified biology from prediction failure. Without an independently justified contrast and committed assay access, this aim remains serially dependent and infeasible.

### R00 direction

Extend the supported context-response question to a defined transport setting using portable resources and an independent experimental partnership. Do not promise universal cross-disease or joint-intervention prediction before support exists.

**Aim judgment:** connected and potentially measurable, but feasibility is not yet demonstrated. Atlas curation, portal development, multimodal alignment, new attention, a conditional VAE and prospective biology together exceed the evidence-supported scope. Obtain premise/assay feasibility before submission; the award cannot be asked to resolve every foundational uncertainty.

# APPROACH — 8

## Estimand and causal identification

The PDF's identity-matched environment swap compares different observed cells. Their state, donor, layer, pathology, survival and technical quality can differ despite similar identity embeddings. It tests conditional prediction, not paired counterfactual ground truth.

```text
Observed prediction: m(c,e,x) = E[Y | C=c, E=e, X=x]
Simulated contrast: m(c,e',x) - m(c,e,x)
Intervention target: E[Y(e') - Y(e) | C=c, X=x]
```

Equating the latter two requires a well-defined exposure, consistency, overlap and a defensible confounding/selection argument. Spatial interference further complicates a manipulation of neighboring cells. Baseline identity is preferable for an intervention question; holding post-exposure identity fixed may condition on part of the response itself.

## Leakage and measurement

- Split donors before feature selection, normalization fitting, imputation, alignment, module discovery and tuning. Keep all sections/modalities of test donors out of training for an unseen-donor claim.
- Disjoint identity/target genes are necessary for some designs but do not establish disentanglement; correlated proxies and pretrained encoders can still carry activity information.
- Exclude focal self-neighbors; audit segmentation spillover and technical spatial autocorrelation.
- Define inference-time inputs. Measured neighbors in an observed test tissue may be legitimate for conditional prediction. Future response measurements are not legitimate inputs to a prospective response forecast.
- Match repeated tissue sections and modalities explicitly. Shared donor labels do not establish cell pairing or section registration.
- Score measured held-out outcomes, not the same imputer's pseudo-targets. Assess measured-only sensitivity and confidence calibration before using imputed values for disease inference.
- Gene-held-out validation is not donor-, environment- or perturbation-held-out validation.

Sources: [[02_Projects/AIVC/project-outline]], [[02_Projects/GeneBridge/datasets]], [[02_Projects/GeneBridge/methods]].

## Unsupported joint queries

Unperturbed spatial tissue plus dissociated perturbation data does not by itself identify an environment-by-perturbation interaction. Separate environment-only, perturbation-only and joint queries, with explicit observed support and validation for each. A control code is not an experimentally observed control in every environment. Abstain from unsupported combinations.

## Statistical plan — proposed, not executed

For measured activity prediction, begin with exact nested baselines:

```text
M0: Y_u = alpha + B_C C_u + B_X X_u + epsilon_u
M1: Y_u = alpha + B_C C_u + B_E E_u + B_X X_u + epsilon_u
```

Here Y is a frozen measured target vector, C permitted identity features, E a fixed neighborhood summary, and X prespecified deployment-available covariates. Use regularized multi-output regression with tuning restricted to training donors. Compare a separate interaction/MLP extension rather than silently adding it to M1. Test-donor identity cannot be a learned categorical predictor for an unseen-donor claim.

Primary prediction endpoint: donor-averaged measured-target loss with training-defined scaling and paired model differences. Use independent biological units for uncertainty; folds and cells are not independent replicates. A distributional response task needs its own prespecified population metric; energy distance is not automatically appropriate for the PDF's conditional-mean task.

For a prospective functional endpoint, an initial candidate formula is:

```text
F ~ exposure * perturbation + Age + Sex + batch + (1 | donor)
```

Specify the response family, actual experimental unit, exposure/perturbation coding, dose/time and additional nested structure from the real assay. Omit or replace terms unsupported by the design; random effects do not repair complete confounding. Randomize within the available design and model dependence accordingly. Use replicate-level pilot variance for power/precision, not cell counts. Freeze tested gene/program families and multiplicity rules.

Potential confounding includes age, pathology, sex, cell composition, layer, tissue quality, postmortem interval and batch. Choose adjustment from the estimand and data-generating model, not an indiscriminate covariate list; do not adjust away a mediator when estimating a total effect.

## Validation and implementation gaps

Combine refitted ablations, which test available information, with frozen-checkpoint replacements, which test fitted reliance. Match replacements within plausible support and relevant cell-type/layer/technical strata. Preserve a final cohort from architecture and audit-driven model selection.

The source still leaves the PDF's `4g` indexing and attention aggregation unspecified. If sparsity means L1 on normalized nonnegative attention, it cannot induce sparsity; the source does not confirm that penalty, so this remains conditional. The diagram's `q(z|c,e,p)` needs a complete training-posterior/prior/likelihood specification, and `L_identity` needs an explicit relation to the total loss. These are unresolved design questions, not observed implementation failures.

# TOP 3 EXPERIMENTS TO PRIORITIZE

## 1. Measured-target context-value and input-use test

First lock dataset/access, donors, target and deployment inputs. Compare identity-only ridge, identity-plus-pooled-context ridge and a small pooled-context MLP under identical donor-held-out tuning. Only then compare attention. Score measured targets with per-donor losses, refitted ablations and matched frozen-model context replacements. A changed output without improved target loss does not pass. Keep an independent test protected.

A SCZ/GeneBridge pilot can establish engineering feasibility now, but must not be presented as aging/AD preliminary evidence. For the NIA premise, repeat in a genuinely relevant and eligible system.

## 2. GeneBridge disease-effect preservation

Lock current files, gene folds, donor exclusions and normalization. Apply one appropriate repeated-donor model to measured and held-out-gene imputed values, for example:

```text
expression ~ Dx + Age + Sex + layer + batch + (1 | donor)
```

This is a proposed formula, not the verified historical analysis. Confirm response scale/error model and rank/estimability before fixing the actual specification. Compare effect sizes, directions, calibration and uncertainty over the same gene universe. Assess null behavior with donor-level permutations only under defensible exchangeability; otherwise use a covariate-aware method. This protects biological claims and publication readiness, not AD or perturbation competence.

## 3. Prospective environment-by-perturbation validation

Use one accessible aging/AD-relevant neural/glial system, defined exposure, limited perturbation set, matched controls, independent biological replication, manipulation checks and a functional endpoint. Freeze both baseline and model predictions before measurement. Use pilot variance to size replication. If assay access is absent, that is a feasibility blocker to resolve, not a completed experiment to imply.
