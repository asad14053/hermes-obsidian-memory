# Communication Preferences

- Prefer direct, practical wording.
- For simple questions, prefer concise answers.
- When asking “in short,” keep it genuinely short.
- When asking for bullets, use bullets.
- Advisor/collaborator messages: concise, respectful, natural.
- Slack/text should not read like a formal email.
- For technical setup:
  - provide copy/paste commands,
  - explain what output to expect,
  - avoid unnecessary theory before the command.
- Historically prefers small steps (“one at a time”); later accepted 2–3 steps together.
- In terminal-only environments, do not assume GUI editor access.
- When asked “next,” continue the established workflow without restarting.
- Bangla ↔ English should be fluent and natural, not awkward literal translation.
- For slides, useful structure is:
  - on-slide text,
  - figure plan,
  - hook/transition question,
  - spoken text only when requested.
