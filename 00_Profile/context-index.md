## Canonical knowledge

Obsidian is the canonical long-term project knowledge base.

Retrieve only the smallest relevant context on demand, with newer notes preferred over older notes:

- project files
- papers
- experiment history
- collaborators
- historical notes
- errors and fixes

Flag contradictions instead of silently selecting one source. Do not change canonical project facts without supporting new evidence.
